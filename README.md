QR · 제품 문자 일치 검사
GitHub Pages에서 실행하는 QR 코드 + OCR 문자 일치 검사 웹앱입니다.
GitHub Pages 올리기
GitHub에서 새 Repository를 만듭니다.
`index.html`을 업로드합니다.
Repository → Settings → Pages로 이동합니다.
Source를 `Deploy from a branch`로 선택합니다.
Branch는 `main`, 폴더는 `/ (root)`로 선택하고 Save 합니다.
잠시 후 `https://사용자이름.github.io/Repository이름/`으로 접속합니다.
사용
QR 카메라 시작 → QR을 읽습니다.
문자 카메라 시작 → 제품의 인쇄 문자를 화면에 맞춥니다.
문자 촬영·판독을 누릅니다.
QR과 OCR 결과가 정확히 같으면 합격, 다르면 불합격입니다.
주의: OCR은 인쇄 품질/폰트/조명에 따라 오인식할 수 있습니다.
